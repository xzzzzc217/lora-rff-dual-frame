# 三、非深度学习下最值得写的几个创新点

------

## 创新点1：连续双帧协同射频指纹特征集

不要只写“双帧 CFO”，而是定义一个完整的**连续双帧协同特征集**，分成 5 类：

### 1）双帧频偏稳态特征

设两帧 CFO 分别为 (\hat{\varepsilon}_1,\hat{\varepsilon}_2)，定义：

[
f_{\text{cfo}}=
\left[
\hat{\varepsilon}_1,;
\hat{\varepsilon}_2,;
\frac{\hat{\varepsilon}_1+\hat{\varepsilon}_2}{2},;
\hat{\varepsilon}_2-\hat{\varepsilon}_1,;
\frac{|\hat{\varepsilon}_2-\hat{\varepsilon}_1|}{|\hat{\varepsilon}_1|+|\hat{\varepsilon}_2|+\epsilon}
\right]
]

这组特征体现：

- 设备本振绝对偏差；
- 连续发射时的频偏漂移；
- 双帧之间的相对稳定性。

------

### 2）双帧相位耦合特征

设每帧前导码第 (m) 个 chirp 的主峰相位为 (\phi_{k,m})，则定义：

[
d_m=\phi_{2,m}-\phi_{1,m}
]

再定义统计量：

[
\mu_d=\frac{1}{M}\sum_{m=1}^{M} d_m
]

[
\sigma_d^2=\frac{1}{M}\sum_{m=1}^{M}(d_m-\mu_d)^2
]

[
\Delta d_m=d_{m+1}-d_m
]

[
E_d=\sum_{m=1}^{M-1}(\Delta d_m)^2
]

这些量能表征：

- 连续两帧之间的残余相位耦合关系；
- 相位漂移平滑程度；
- 硬件瞬态差异。

------

### 3）双帧幅度纹理特征

设两帧前导峰值幅度分别为 (A_{1,m},A_{2,m})，定义：

[
r_m=\frac{A_{2,m}}{A_{1,m}+\epsilon}
]

再定义：

[
\mu_r=\frac{1}{M}\sum_{m=1}^{M} r_m,\quad
\sigma_r^2=\frac{1}{M}\sum_{m=1}^{M}(r_m-\mu_r)^2
]

以及双帧能量差分：

[
\Delta E = \log \left(\sum_n |x^{(2)}[n]|^2 + \epsilon \right)
-\log \left(\sum_n |x^{(1)}[n]|^2 + \epsilon \right)
]

这个部分可以体现功放、DAC、链路切换细节差异。

------

### 4）双帧瞬态过渡特征

连续双帧最值得挖掘的一个点就是**第一帧结束到第二帧开始之间的切换行为**。

定义第一帧尾部窗口 (u_1[n]) 与第二帧头部窗口 (u_2[n])，构造：

- 包络上升斜率；
- 包络下降斜率；
- 相位旋进速度；
- 切换间隔归一化偏差。

例如包络：

[
e_k[n]=|u_k[n]|
]

上升斜率：

[
s_k=\frac{1}{L_t-1}\sum_{n=1}^{L_t-1}(e_k[n]-e_k[n-1])
]

切换差异：

[
f_{\text{tran}}=[s_1,s_2,s_2-s_1]
]

这个点非常适合写专利，因为很多现有方法只看单帧内部，你这个可以强调“**连续双帧之间的发射切换微行为是新的指纹来源**”。

------

### 5）双帧一致性与稳定性特征

定义多种一致性指标：

[
\rho_{\text{cfo}}=\exp\left(-\frac{|\hat{\varepsilon}_2-\hat{\varepsilon}_1|}{\lambda_1}\right)
]

[
\rho_{\text{pha}}=\exp\left(-\frac{\sigma_d^2}{\lambda_2}\right)
]

[
\rho_{\text{amp}}=\exp\left(-\frac{\sigma_r^2}{\lambda_3}\right)
]

构成：

[
f_{\text{rel}}=[\rho_{\text{cfo}},\rho_{\text{pha}},\rho_{\text{amp}}]
]

这类特征既能用于分类，也能用于样本质量评价。

------

## 创新点2：信道扰动抑制的“双帧差分稳定化”机制

这是可以替代深度学习“解耦”的关键创新。

基本思想：
**信道在连续双帧短时间内近似缓变，而设备硬件误差在双帧上保持同源；**
因此通过构造合适的差分、比值、归一化和残差，可以削弱信道共同成分。

### 1）共模消除

对于特征 (g_1,g_2)，定义：

[
g_{\text{cm}}=\frac{g_1+g_2}{2},\quad
g_{\text{df}}=g_2-g_1
]

其中：

- (g_{\text{cm}}) 描述稳定共同分量；
- (g_{\text{df}}) 描述微差异分量。

两者拼接比只用一个值更强。

### 2）比值归一化

对受增益影响较大的特征用比值代替差值：

[
g_{\text{ratio}}=\frac{g_2}{g_1+\epsilon}
]

### 3）局部趋势消除

若某帧内 chirp 级特征序列为 (z_m)，做局部线性去趋势：

[
\tilde z_m = z_m - (am+b)
]

其中 (a,b) 由最小二乘拟合得到。这样能消除缓慢变化的信道漂移，只保留细微硬件纹理。

这部分可以单独作为一个专利创新模块：
**“一种基于连续双帧共模抑制与局部去趋势的 LoRa 射频指纹稳定化方法”。**

## 创新点3：可靠性自加权特征融合

不用深度学习，也能做“智能加权”。

给每个样本构造质量指标：

- 同步峰值强度 (q_1)
- 主峰能量集中度 (q_2)
- 双帧 CFO 一致性 (q_3)
- SNR 估计 (q_4)

组合成质量分数：

[
Q = \sum_{i=1}^{4}\alpha_i q_i
]

再把各类特征的权重设计成：

[
w_j = \frac{\exp(\beta_j Q_j)}{\sum_k \exp(\beta_k Q_k)}
]

最终融合特征：

[
f = [w_1 f_{\text{cfo}},, w_2 f_{\text{pha}},, w_3 f_{\text{amp}},, w_4 f_{\text{tran}},, w_5 f_{\text{rel}}]
]

这样就不是简单拼接，而是**按样本质量动态赋权**。这很适合专利表述。

## 创新点4：判别子空间映射，不用深度学习也能很“高级”

你可以不用神经网络，而用一个**加权分块判别投影**方法。

设总特征为 (f)，希望求一个投影矩阵 (W)，使不同设备尽量分开、同一设备尽量聚拢，同时考虑不同特征块的重要性。

定义类内散度：

[
S_w=\sum_{c=1}^{C}\sum_{i:y_i=c}(f_i-\mu_c)(f_i-\mu_c)^T
]

定义类间散度：

[
S_b=\sum_{c=1}^{C}n_c(\mu_c-\mu)(\mu_c-\mu)^T
]

引入分块权重矩阵 (D) 后，求解：

[
W^*=\arg\max_W \frac{\operatorname{tr}(W^T D S_b D W)}{\operatorname{tr}(W^T D S_w D W)+\lambda |W|_F^2}
]

这本质上是一个**加权正则化判别投影**。
优点：

- 完全非深度学习；
- 数学形式漂亮；
- 非常适合写专利；
- 比 KNN 直接分类更显创新。

## 创新点5：分层原型图分类器

这是替代 KNN 的最好选择之一。

### 第一层：粗分类

先按芯片类型/设备型号/频偏区间做粗筛选，减少候选类别。

例如通过原型均值做初筛：

[
\mathcal{C}_0 = {c \mid |\bar{\varepsilon}-\bar{\varepsilon}*c|<T*\varepsilon}
]

### 第二层：原型距离判别

每个设备建立原型中心 (\mu_c)，计算：

[
d_c=(z-\mu_c)^T\Sigma_c^{-1}(z-\mu_c)
]

### 第三层：邻域图修正

对候选设备构造邻接图，边权为：

[
A_{ij}=\exp\left(-\frac{|\mu_i-\mu_j|^2}{\sigma^2}\right)
]

用局部图平滑修正分类分数：

[
s'*i = s_i + \eta \sum*{j\in \mathcal N(i)} A_{ij}s_j
]

### 第四层：拒识判断

若最优类别与次优类别差距过小，或最大置信度低于阈值，则拒识：

[
\max_i s'*i < \theta_1
\quad \text{or} \quad
s'*{(1)}-s'_{(2)}<\theta_2
]

则判定为未知设备或低可信样本。

这套结构比 KNN 更完整、更适合专利。
